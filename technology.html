Технологии и программы

Используемые программы и технологии

Этот проект создан в образовательных целях для демонстрации возможностей замкнутого ядерного цикла и технологий будущего.

Blender 3D

Это мощный бесплатный пакет для создания 3D-графики. В рамках этого учебного проекта он мог бы использоваться для:

  • Моделирования 3D-объектов: Создания моделей реактора, зданий энергоблока или других объектов для визуализации.
  • Создания анимации: Настройки движений, симуляции процессов, происходящих в реакторе.
  • Работы с текстурами: Придания материалам реалистичного вида (металл, бетон и т.д.).
  • Рендеринга сцен: Создания высококачественных изображений или видео для презентации проекта.
  • Добавления визуальных эффектов: Генерирования дыма, пара или других эффектов.

Сайт

Для создания этого образовательного веб-сайта использовались базовые технологии фронтенд-разработки:

  • HTML: Для разметки и структурирования контента страниц.
  • CSS: Для стилизации, оформления и обеспечения адаптивности (через файлы global.css, main.css, project.css).
  • JavaScript: (В данном макете не используется активно) Предназначен для добавления интерактивности, такой как слайдеры, всплывающие окна или динамическая подгрузка контента.

IDE: Visual Studio Code

Visual Studio Code Весь код этого сайта был написан в среде разработки.

Это популярный, бесплатный редактор кода от Microsoft, который поддерживает подсветку синтаксиса для HTML, CSS и JavaScript, а также имеет множество расширений (плагинов) для упрощения и ускорения процесса веб-разработки.
